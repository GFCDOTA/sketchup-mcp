# sketchup-mcp — instruções para Codex CLI

Siga [as instruções de produto](.claude/CLAUDE.md), inclusive os gates de fidelidade, revisão visual humana e o fluxo de PR para `develop`.

Skills reutilizáveis e contratos compartilhados pertencem a `Plan2Space/claude-engineering-skills`; SPECs de produto, código, testes e evidências SketchUp permanecem aqui. Consulte o contrato `contracts/ownership.v1.md` e `catalog/skills.json` do hub na release `v0.9.3`, commit `3f93ccb001d4609527587ddfa1a716ca5a09b38c`. Leia e verifique a skill antes de aplicá-la; registre nome, SHA, SPEC, issue, PR, evidência e resultado. O loader automático é a issue central #29.

Use `spec-author`, `spec-progress-keeper` e `backlog-governance` conforme o trabalho; atualize a SPEC após marcos e antes do handoff. Priorize o Board por dependências, risco, impacto e critérios de aceite. Não altere permissões, proteção de branch ou políticas de aprovação sem autorização.
